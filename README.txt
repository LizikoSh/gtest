4GARMIN — СТАТИЧНА ГОЛОВНА СТОРІНКА

Як відкрити:
1. Розпакуйте ZIP-архів.
2. Відкрийте файл index.html подвійним кліком.

Як опублікувати на GitHub Pages:
1. Завантажте весь вміст цієї папки в корінь репозиторію.
2. На GitHub відкрийте Settings → Pages.
3. У розділі Build and deployment виберіть Deploy from a branch.
4. Виберіть main і папку /(root), потім Save.

Основні файли:
- index.html — структура головної сторінки;
- style.css — дизайн та адаптивність;
- script.js — меню, пошук, вкладки, обране, порівняння та кошик;
- images — усі зображення;
- favicon.svg — іконка вкладки.

# 4Garmin Storefront

Адаптивний демонстраційний макет головної сторінки інтернет-магазину Garmin.

## Що реалізовано

- верхня інформаційна смуга та адаптивна шапка;
- пошук із фільтрацією товарів;
- меню каталогу;
- hero-банер і бокові промобанери;
- переваги магазину;
- вкладки товарів;
- обране, порівняння та лічильник кошика;
- популярні категорії;
- промобанери та YouTube-секція;
- адаптація для планшетів і смартфонів.

## Локальний запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

## Основні файли

- `app/page.tsx` — структура сторінки та інтерактивність;
- `app/globals.css` — оформлення й адаптивність;
- `public/images` — фонові та товарні зображення.

Тексти, товари, ціни, посилання й контакти в макеті демонстраційні та легко
редагуються в масивах на початку `app/page.tsx`.
